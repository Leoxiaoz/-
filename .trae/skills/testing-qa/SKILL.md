# Testing / QA（测试 / 质量保障）

> 占位框架文档。正式内容将在提供完整「游戏制作规划」后，由制定者据此定制。

## 定位

本 Skill 聚焦游戏**质量保障与验证**规约：如何验证功能闭环、如何检查数值与资源循环、如何覆盖边界与异常、如何保证回归与存档迁移安全。当前为通用框架占位，**不自行决定具体技术栈、测试工具与项目结构。**

## 适用范围

- 单机、手机端、文字/模拟经营类游戏的功能验证与质量评估
- 尚未最终确定测试工具链与跑测方式的早期阶段

## 待定项（占位，不预先决定）

以下内容**保持空白**，等待「游戏制作规划」提供后再填充：

- [ ] 测试工具链与运行方式（自动化 / 手动 / 组合，频次）
- [ ] 测试范围与用例清单（核心玩法、存档、配置、边界）
- [ ] 关键数值平衡的指标口径（来源/消耗/上限/概率）
- [ ] 存档兼容的迁移用例清单
- [ ] 回归与发布准入门槛

## 通用规约框架（与具体项目无关的原则占位）

1. **逻辑性/合理性校验**：可运行、交互闭环、数值自洽（无负数/NaN/undefined/越上限）、显示与结算一致。
2. **状态一致性校验**：核心状态字段在创建、存档、读取、跨周期推进后值一致，缺省字段有兜底。
3. **存档兼容校验**：数据结构变更可正常读写旧档、不崩溃，迁移有版本号与用例。
4. **资源与获取循环校验**：来源可得、消耗有处去、循环闭合、回收有出口、防刷防爆；验证结论需反馈给制定者，指出隐患与建议系数。
5. **边界与异常**：为空、为零、满上限、重复操作、快速连点时，不报错、不卡死、不重复发放。
6. **可复查**：用例可追踪、结果可复现，验证结论成文便于交接。

## 使用方式

- 收到「游戏制作规划」后，由制定者审阅并填充「待定项」，正式定制本 Skill。
- 本文件为占位说明，暂不包含任何具体测试实现。
