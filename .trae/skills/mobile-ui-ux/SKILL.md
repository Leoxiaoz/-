# Mobile UI/UX（移动端界面与交互）

> 占位框架文档。正式内容将在提供完整「游戏制作规划」（含平台约束与视觉风格）后，由制定者据此定制。

## 定位

本 Skill 聚焦**手机端界面与交互**规约：布局与适配、触摸交互、反馈与空态、视觉一致性。当前为通用框架占位，**不自行决定具体技术栈、目录结构、视觉风格与交互实现方式。**

## 适用范围

- 单机、手机端、文字/模拟经营类游戏的界面设计与交互定义
- 尚未最终确定 UI 方案与视觉风格（以文字为主的界面表现）的早期阶段

## 待定项（占位，不预先决定）

以下内容**保持空白**，等待「游戏制作规划」提供后再填充：

- [ ] 屏幕适配策略与断点（竖/横屏、不同尺寸）
- [ ] 信息层级与导航结构（首页/弹窗/抽屉等）及其与交互入口的关系
- [ ] 触摸/手势规范（点按、滑动、长按、双击）
- [ ] 反馈与空态/加载/错误态的视觉约定
- [ ] 色彩、字体、动效等视觉风格规范

## 通用规约框架（与具体项目无关的原则占位）

1. **一目了然**：核心信息优先可见，层级清晰，关键操作入口可达。
2. **触摸友好**：目标尺寸与间距适配手指操作，减少误触。
3. **即时反馈**：每次操作有明确反馈（变化、提示、可关闭的弹窗/抽屉），可退出回到上一步。
4. **一致性强**：复用统一组件与样式变量，避免散落魔法数值。
5. **边界界面完整**：空态、加载、错误、满限、重复点击等场景有合理表现，不卡死、不白屏。
6. **可适配**：布局能适配不同屏幕并保持核心交互可用。

## 使用方式

- 收到「游戏制作规划」后，由制定者审阅并填充「待定项」，正式定制本 Skill。
- 本文件为占位说明，暂不包含任何具体界面实现。
